# Domain Docs

InviteCodeKt is a single-context repository.

Before changing domain behavior:

1. Read `/CONTEXT.md`.
2. Read relevant ADRs under `/docs/adr/`.
3. Use the canonical terms from `CONTEXT.md`.
4. Surface conflicts with an ADR instead of silently overriding it.

`CONTEXT.md` is a glossary, not an implementation specification. Add terms through domain modeling when the shared language changes. Create ADRs only for hard-to-reverse decisions with meaningful trade-offs.
