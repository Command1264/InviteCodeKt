# Triage 標籤

| 標準角色 | GitHub 標籤 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待維護者評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可由 Agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要人類實作、判斷或驗收 |
| `wontfix` | `wontfix` | 決定不處理 |

Skill 提到標準角色時，使用本表對應的 GitHub 標籤。
