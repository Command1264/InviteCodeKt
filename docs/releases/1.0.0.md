## 功能摘要

- **邀請關係：** 玩家持有六字元十六進位 Color Invite Code。符合 Claim Eligibility 的 Invitee 可在 Claim Window 內建立唯一 Invitation，並在確認 Inviter 摘要後完成 Claim。Invitation 與 Qualification 分階段處理；管理員可執行具稽核紀錄的 Unlink、Eligibility Reset、未 qualified Invitation Transfer 與 Force Qualification。
- **玩家流程與平台：** 支援 `/invitecode claim <code>`、舊版私密聊天輸入，以及新版 Paper／Spigot 原生 Dialog 輸入與確認。1.16 以上 client 可顯示 Color Invite Code 的 RGB 色彩；舊版使用最接近的 legacy color。另有玩家 status／stats 與管理指令。新式 Dialog 按鈕底色由 client 控制。
- **資格判定：** Qualification Policy 由 OR group 與 AND condition 組成，內建遊玩時間、經過時間、不同登入日、permission、PlaceholderAPI 比較及管理員核准條件，並支援外部 provider。保存穩定 policy ID、不可變 revision 與 Qualification Fact；未知或失敗的 provider 不應使 Invitation 自動 qualified。
- **獎勵交付：** 支援 Qualification Reward、Inviter Milestone Reward、message、console command、player command 與 Vault Economy Action。先保存具冪等鍵的 Delivery／Action，再執行；玩家離線時可保留 Pending Reward。外部結果不明時標記 `UNCERTAIN`，只由管理員依稽核資訊決定後續處理，不自動重播。
- **儲存與維運：** SQLite 與 MySQL 8.4 為 production backend；JSON 適用小型單實例。支援明確 schema migration、離線跨 backend 搬移、離線玩家匿名化、唯讀 doctor、設定 reload 與版本化設定／語系。網路防濫用使用有期限 HMAC-SHA-256 hash，不保存原始 IP。
- **相容性：** 以單一 Java 8 相容 JAR 支援已測試的 Spigot／Paper 版本，不使用 NMS，較新 API 隔離於 adapter。Folia 支援為實驗性。

- **指令與診斷：** 支援繁中與英文訊息、分層指令說明及權限分級補全。玩家 status 顯示目前登記批次，stats 保留累計。doctor 顯示 Git 提交前七碼及 UTC 打包時間。

以下保留發版時採用的核對項目；實際完成結果與各候選的證據範圍見[結案依據](./1.0.0-closeout.md)及下方支援清單，不表示每個核心都以最終 JAR 重跑完整真人流程。

2. 用同一個 JAR 驗證代表性核心上的啟用、help、reload、狀態與 doctor。比對 JAR manifest 的 Git 版本及 UTC 打包時間。

4. 產品採 Apache-2.0。發布時同時提供對應 InviteCode 原始碼與 Connector/J 原始碼附件，並核對第三方聲明。[散布清單](../../third-party/THIRD-PARTY-NOTICES.md) · [舊候選授權盤點](dependency-notice-inventory.md)
5. 正式發布前核准最終提交、main 整合、tag 與發布。保留正式版 release 基線供 hotfix，已發布 tag 保持固定。
